# Rules de trabajo

> Leer estas reglas al inicio de cada sesión para entender cómo trabajar.

1. **Optimización:** entregar cada aspecto del plan lo más optimizado posible.
2. **Arquitectura limpia:** usar patrones arquitectónicos robustos que permitan una integración fluida sin cruzar elementos entre las capas del negocio (desacoplamiento de dominios).
3. **Especialización:** pensar como especialista en cada área y actuar como alguien especializado en su área.
4. **Validación:** validar todo; no entregar errores ni falsos positivos.
5. **Excelencia:** no detenerse hasta obtener el mejor resultado posible.
6. **Memoria:** antes de terminar una sesión, guardar memoria de todo lo realizado.
